# Contributing

## Getting started

1. Fork the repository and clone your fork.
2. Copy the OutSystems platform assemblies into `Source/NET/Bin/` (see [Build and Deployment](README.md#build-and-deployment)). They aren't committed because they are proprietary.
3. Open `Source/NET/GoogleCloudStorage_ext.sln` in Integration Studio, or build with MSBuild:
   ```
   msbuild Source/NET/GoogleCloudStorage_ext.csproj /p:Configuration=Release
   ```

## Workflow

1. Create a branch from `master`:
   ```
   git checkout -b feature/short-description
   ```
2. Make the change in focused commits.
3. Check that the extension compiles with no warnings (Integration Studio Verify, or the MSBuild command above).
4. Run the tests with `tests\run-tests.ps1 -Download` (no Google credentials needed; see [tests/README.md](tests/README.md)). All tests must pass.
5. Open a pull request against `master` that explains the change and why.

## Code conventions

- Target .NET Framework 4.8, and use C# 6 language features at most, like the existing code.
- Match the existing style: tabs, XML doc comments on every action, and the `ss`/`Mss` naming of the generated code.
- `Interface.cs`, `Structures.cs`, `Records.cs` and `RecordLists.cs` are generated by Integration Studio. Change actions and structures in Integration Studio first, then update the code.
- Keep hand-written code in `GoogleCloudStorage_ext.cs`. Integration Studio did not carry an added file (`Directory.Build.props`) through its `.xif`, so a new source file could be lost the same way.
- Each action converts its `Authentication` record with `FromRecord` and gets clients and signers from `GetStorageClient` / `GetUrlSigner`, which cache them per credential.
- Read timestamps through `ParseTimestamp`. The SDK's `*DateTimeOffset` properties reject some valid RFC 3339 values.

## Dependencies

The third-party DLLs in `Source/NET/Bin/` are committed. When you update one:

- Replace the DLL and its XML in `Bin\`, and update the matching `<Reference>` version in `GoogleCloudStorage_ext.csproj`.
- Use the `net462` build of `Google.*`, `System.*` and `Microsoft.*` packages, and the `net45` build of `Newtonsoft.Json`.
- List the old and new versions in the pull request.

## Reporting issues

Include:
- the connector version or commit;
- the OutSystems 11 platform version;
- the action and inputs used (with credentials removed);
- the full error message or the unexpected behaviour.
